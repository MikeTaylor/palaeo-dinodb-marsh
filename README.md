# palaeo-dinodb-marsh

In 2010, Matt Wedel, Randy Irmis and Mike Taylor put a lot of [O. C. Marsh](https://en.wikipedia.org/wiki/Othniel_Charles_Marsh)'s papers up on [marsh.dinodb.com](http://marsh.dinodb.com/). It went offline some time around 2024 due to various server moves. This repository contains [the HTML front page](htdocs/index.html), [the PDFs](htdocs/marsh/) and the Apache configuration to serve these files from a new server.
